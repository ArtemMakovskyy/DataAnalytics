# Модулі та пакети в Python

Навчальний проєкт, який показує, як створювати модулі, пакети та імпортувати їх різними способами.

## Що таке модуль

**Модуль** — це окремий файл Python (наприклад, `math_utils.py`), який містить функції, класи, константи та інший код. Ім'я модуля — це ім'я файлу без розширення `.py`. Модуль можна імпортувати в інший файл і використовувати його вміст.

## Що таке пакет

**Пакет** — це папка з модулями, яка містить файл `__init__.py` (у сучасному Python він не обов'язковий, але його використовують для явного оформлення пакета та зручного експорту). Наприклад, папка `shop/` — це пакет, а `shop.payments` — вкладений підпакет.

## Навіщо потрібен `__init__.py`

- позначає папку як пакет (для класичного підходу);
- виконується під час імпорту пакета;
- дозволяє зробити зручний публічний інтерфейс, наприклад:

```python
from .cart import add_to_cart
from .products import get_product

__all__ = ["add_to_cart", "get_product"]
```

Після цього можна писати `from shop import add_to_cart`.

## Типи імпортів

### Абсолютний імпорт

Вказує повний шлях від кореня проєкту:

```python
import math_utils
from math_utils import add, PI
import math_utils as mu
from shop.payments.card import pay
```

Абсолютні імпорти вважаються кращими для великих проєктів, бо вони однозначні.

### Відносний імпорт

Вказує шлях відносно поточного модуля всередині пакета:

```python
from .products import get_product
```

- `.` — поточний пакет (папка, у якій лежить модуль);
- `..` — батьківський пакет.

Наприклад, із `shop/payments/card.py` запис `from ..cart import add_to_cart` означав би «піднятися з `shop.payments` до `shop` і взяти `cart`».

Відносні імпорти працюють лише всередині пакета. Їх не можна використовувати у скрипті, який запускається напряму (`python shop/cart.py`), бо тоді модуль не має інформації про свій пакет.

## Типові помилки

- **`ModuleNotFoundError`** — Python не знайшов модуль. Перевірте, чи файл існує, чи правильний шлях і чи запускаєте ви команду з потрібної папки.
- **Циклічні імпорти** — модуль `a` імпортує `b`, а `b` імпортує `a`. Виносьте спільний код в окремий модуль або робіть імпорт усередині функції.
- **Збіг імені зі стандартним модулем** — файл `random.py` або `math.py` у проєкті може перекрити стандартний модуль Python. Не називайте свої файли так само, як модулі стандартної бібліотеки.
- **Відносний імпорт у скрипті, що запускається напряму** — `python shop/cart.py` із `from .products import ...` завершиться помилкою `ImportError: attempted relative import with no known parent package`. Запускайте пакет через `python -m shop` або імпортуйте модуль ззовні.

## Як запускати приклади

Усі команди виконуються з папки `modules.packages`:

```bash
python main.py
python math_utils.py
python basic_types.py
python -m shop
```

Зверніть увагу: назва папки `modules.packages` містить крапку, тому вона не є пакетом Python і не містить `__init__.py`. Приклади запускаються зсередини цієї папки.

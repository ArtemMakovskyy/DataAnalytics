У Python немає `===` (воно є в JavaScript). Ось що є замість нього:

|Оператор|Що робить|Приклад|
|---|---|---|
|`=`|Присвоєння, а не порівняння|`x = 5`|
|`==`|Порівнює **значення**|`[1, 2] == [1, 2]` → `True`|
|`!=`|Не дорівнює (напевно, ви мали на увазі саме його, а не `-==`)|`3 != 4` → `True`|
|`is`|Порівнює **ідентичність**, тобто чи це один і той самий об'єкт у пам'яті|`a is b`|
|`is not`|Протилежне до `is`|`a is not b`|
|`<`, `>`, `<=`, `>=`|Більше/менше|`3 <= 3` → `True`|
|`:=`|Walrus: присвоєння всередині виразу|`if (n := len(s)) > 3:`|

Найближчий аналог `===` це `is`, але вони не тотожні. `==` перевіряє рівність значень, а `is` перевіряє, чи це той самий об'єкт.

python

```python
a = [1, 2]
b = [1, 2]
c = a

print(a == b)   # True  (значення однакові)
print(a is b)   # False (це два різні списки)
print(a is c)   # True  (це той самий об'єкт)
```

`is` зазвичай використовують лише для `None`, `True` і `False`:

python

```python
if x is None:
    ...
```

Не варто застосовувати `is` для чисел і рядків. Результат може залежати від внутрішнього кешування в Python:

python

```python
a = 1000
b = 1000
print(a == b)   # True
print(a is b)   # може бути False
```

Також Python дозволяє ланцюжки порівнянь, чого немає в Java:

python

```python
if 1 < x <= 10:     # те саме, що 1 < x and x <= 10
    ...
```
